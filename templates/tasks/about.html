About Student Task & Performance Management System

1. System Overview

The Student Task & Performance Management System is a full-stack web application designed to help university and college students systematically organize academic coursework, laboratory assignments, and project deliverables while tracking personal performance metrics in real time.

2. Core Objectives
  • Coursework Organization: Centralize assignments across multiple academic subjects with custom priorities, status tags, and deadlines.
  • Automated Overdue Detection: Systematically detect missed deadlines without requiring manual intervention.
  • Performance Analytics: Provide real-time task completion ratios, priority breakdowns, and milestone tracking.
  • Strict Data Isolation & Security: Enforce complete user privacy so each student can access only their own records.
3. Technology Architecture
Backend Architecture
  • Python 3: High-performance, clean programming language.
  • Django Web Framework: Model-View-Template (MVT) architecture.
  • Django ORM: Object-Relational Mapping for safe SQL operations.
  • Django Authentication: Built-in session security and password hashing.
  • SQLite: Serverless, zero-configuration relational database.
Frontend Presentation
  • HTML5 & CSS3: Semantic and accessible web markup.
  • Bootstrap 5: Responsive grid system, typography, and utility classes.
  • Bootstrap Icons: Vector iconography for intuitive visual indicators.
  • Vanilla JavaScript: Form interactions and client-side usability.
  • Chart.js: Lightweight canvas-based priority statistics visualization.
4. User Roles & Access Levels
Role Permissions & Scope Primary Interface
Student Register, login, create, view, update, delete, search, and filter personal academic tasks. Track performance score. Student Web Portal & Dashboard
Admin / Faculty Manage student accounts, view all tasks across the institution, filter by status, inspect creation dates, and oversee system health. Django Administration Portal
